# 本地点评 · uniapp 客户端

对接 `dianping-backend` 的完整客户端。HBuilderX 导入即用，一个工程包含 C 端 + 管理端。

## 页面清单（8 页 + 引导）

| 页面 | 路径 | 说明 |
|---|---|---|
| 登录 | pages/login/login | 手机号+验证码，新号自动注册 |
| 首页信息流 | pages/feed/feed (Tab) | 地区筛选、卡片流、下拉刷新、上拉加载、行内点赞 |
| 内容详情 | pages/detail/detail | 图片轮播/视频播放、点赞、作者被驳回时显示原因 |
| 发布 | pages/publish/publish (Tab) | 仅点评人可见表单；图文九宫格/视频；选图直传 OSS |
| 我的 | pages/mine/mine (Tab) | 角色徽章、发布数、后台入口（仅管理员） |
| 用户主页 | pages/user/user | TA 的全部上架点评 |
| 后台·内容审核 | pagesAdmin/audit/audit | 待审/已上架/已驳回三个 Tab，通过/驳回/下架 |
| 后台·用户管理 | pagesAdmin/users/users | 搜索、授权/收回点评人、封禁/解封 |

普通用户点"发布"Tab 会看到引导卡片（复制管理员电话）；管理员登录后"我的"页出现后台入口。

## 怎么跑

1. HBuilderX → 文件 → 导入 → 从本地目录导入 → 选 `dianping-uniapp` 文件夹
2. 确认 `utils/config.js` 里的 `BASE_URL`：
   - **浏览器调试**：`http://localhost:18080`（后端 java -jar 起的端口）
   - **真机调试**：改成电脑局域网 IP，如 `http://192.168.1.113:18080`，手机和电脑连同一 WiFi，且电脑防火墙放行该端口
3. 运行 → 运行到浏览器（Chrome）或 运行到手机或模拟器
4. 登录：管理员 `13800000000 / 8888`；随便换个手机号+8888 注册普通用户测角色差异

## 建议的测试顺序

1. 用新手机号登录（普通用户）→ 首页能看信息流 → 点发布看到引导卡片 ✓ 角色隔离 OK
2. 登管理员 → 我的 → 用户管理 → 给新用户"授权点评人"
3. 新用户重登录（重新打开 App 让 token 刷新 role）→ 发布页出表单 → 发一篇图文
4. 管理员 → 内容管理 → 待审里能看到（若后端 audit.mock-auto-pass=false）→ 通过
5. 任意用户首页看到新内容 → 点赞 → 详情页点赞变红

## 已知限制（MVP 边界）

- 视频发布无封面截帧，信息流里视频卡片显示灰块，详情页可直接播放
- 验证码按钮只做倒计时动画，实际固定 8888（后端接短信后再改）
- tabBar 为文字样式（未配图标 png），要图标就往 tabBar.list 里加 iconPath
- H5 端 OSS 直传可能有跨域限制：需在 OSS 控制台配置 CORS 允许你的来源（App 端无此问题）
